# Motorola Mobile Sales Analytics
![alt text](<Screenshot 2026-05-22 235022.png>)
## Project Overview

This project is a Power BI dashboard built to analyze Motorola mobile phone sales data. It provides insights into sales performance, product trends, and revenue distribution to support data-driven business decisions.

---

## Project Structure

```text
01-Motorola Mobile Sales Analytics/
│
├── Motorola Mobile Sales Analytics.pbix
└── Read.md
```

---

## Technologies Used

- Power BI
- DAX (Data Analysis Expressions)
- Power Query

---

## Dashboard Features

- Sales performance overview
- Product-wise and model-wise sales analysis
- Revenue and profit trend analysis
- Regional / category-wise sales distribution
- Interactive filters and slicers for drill-down analysis
